## 개요

개인 프로젝트로 제작한 2D 턴제 게임 'Project : Remnant' 입니다.<br />

Project : Remnant는 게임 'Limbus Company'에서 모티브를 얻어 제작한 프로젝트로,<br />
과거 팀 프로젝트로 진행한 3D 턴제 게임 'Project : Yuria'의 턴제 전투 시스템 개선 및 업그레이드,<br />
'Limbus Company'의 전투 시스템 구현, ECA 패턴 기반 스킬 시스템, 자동 세이브 구현을 목표로 제작하였습니다.
<br />

## **3. 스킬 시스템**

### **A. 구현 정리**

#### ▣ 스킬 시스템
- ECA 패턴 기반 스킬 데이터 구현
- ECA 패턴 스킬 데이터를 읽어 자동으로 설명 스크립트 작성
- 동기화(돌파)에 따른 스킬 강화

<br />

스킬 시스템 구현에서 중요하게 고려한 부분은 데이터 & 동작 분리,<br />
동기화(돌파)에 따른 스킬 데이터 변경 대응, 쉽게 작성 가능한 스킬 데이터 구현입니다.<br />
<br />

---

### **B. 사례**

#### **▣ B-1.특수한 스킬 설계를 고려한 데이터 구조 설계**

- **문제점**<br />
  기존 프로젝트에서 제작한 스킬과 다른 형식으로 동작하는 스킬 데이터 구현

- **고민**<br />
  Project : Remnant의 스킬은 게임 'Limbus Company'의 전투 로직을 구현하는 것을 목표로 하였습니다.<br />
  이때 모티브가 되는 게임의 스킬 구조는 하나의 스킬에 여러개의 코인(공걱 횟수)가 존재하며,<br />
  각 코인마다 부가 효과가 붙어있는 방식으로 구현되어 있습니다.<br />
  또한 부가 효과는 앞에 사용시, 적중시, 앞면 적중시 등 특정 조건을 만족했을 때 효과가 발동하기도 합니다.<br />

  여기에 효과는 단순한 버프 & 디버프 부여, 해당 스킬의 데미지 증가, 치명타 피해량 증가, 해당 코인 재사용 등,<br />
  스킬은 다수의 코인 + 조건 + 효과로 구성되어 있어 기존 개발에서 사용하던 스킬 데이터 제작 방식을 적용할 수 없었습니다.<br />
  
- **해결책**<br />
  ECA 패턴을 기반으로 코인 노드, 조건 노드, 효과 노드를 나눠 구현하여 데이터가 난잡해 지는 것을 방지하였습니다.<br />
  또한 개별 노드로 분리한 덕분에 설명 스크립트 작성 자동화, 동기화(돌파)에 따른 스킬 강화 로직을 구현할 수 있었습니다.<br />
